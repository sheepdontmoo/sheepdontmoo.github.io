Skool About page image size

Skool's Help Center doesn't give an official pixel size for About page images. It only says to upload images or videos showing what's offered, an explainer, and what members are saying. Source: Skool Help Center: How to set up my group's About page?. Most creators use a 16:9 image, such as 1400 x 790 or 1600 x 900 px. That's common practice, not a Skool spec.

What Skool's Help Center does say about the About page

  • The About page is "essentially a landing/checkout page for your group". Add media showing what's offered in the program, an explainer video, and what members are saying (Skool Help Center: How to set up my group's About page?).
  • Links in the About page description don't work, so leave websites and links out (Skool Help Center: How to set up my group's About page?).
  • You must complete the About page for your group to be eligible for Discovery. Discovery also needs About page description/images and a cover image (Skool Help Center: How to set up my group's About page?; Skool Help Center: Discovery FAQs).
  • "High-quality artwork / about page" is a Discovery ranking boost, and "low-quality artwork / about page" is a penalty (Skool Help Center: Discovery FAQs).
  • For paid groups, Skool's ads pull from your About page title, description, images and videos (Skool Help Center: Growth Tab and Skool Ads).

Our tips (not official Skool rules)

  • Put one idea per image, with a big headline and minimal text.
  • Your first About image should support your cover, not repeat it.
  • Check every image at phone size before you upload it.
